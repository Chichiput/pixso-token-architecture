# Архитектура токенов для Pixso

Плагин сканирует Variables открытого файла и подключённых к нему опубликованных библиотек. Коллекции и группы видны в дереве, которое строится по разделителям `/` в именах переменных. В предпросмотре можно выбрать коллекцию и режим, найти токен, посмотреть образец цвета или проследить цепочку ссылок.

## Установка

1. Распакуйте архив и откройте нужный дизайн-файл в настольном Pixso.
2. Откройте панель плагинов и выберите «Создать плагин» / Create Plugin. В некоторых версиях этот пункт доступен через контекстное меню «Плагины → Разработка плагинов».
3. Выберите `manifest.json` из распакованной папки. Оставьте `main.js` и `ui.html` рядом с манифестом.
4. Запустите «Архитектура токенов» из списка локальных плагинов.

Сборка и установка зависимостей не требуются.

## Предпросмотр и экспорт

- «Дерево токенов» показывает значение для выбранного режима. Для прямого значения цвета виден HEX, для ссылки — имя коллекции и путь переменной, на которую она указывает. Если целевая переменная недоступна, виден её идентификатор.
- «Только локальные переменные» ограничивает предпросмотр и JSON коллекциями открытого файла.
- «Обновить» заново читает данные открытого файла.
- «Скачать JSON» выгружает `pixso-tokens.json`. В JSON входят все найденные коллекции и токены независимо от фильтров. Для коллекций открытого файла также сохраняются режимы и значения. Вкладка «JSON» показывает содержимое экспортируемого файла и позволяет скопировать его вручную, если среда Pixso ограничивает скачивание.

## Формат файла

Корневой объект содержит `schemaVersion`, массив `collections` и предупреждения `warnings`. Поле `source` указывает, откуда взята коллекция. У коллекции есть идентификатор, имя, список режимов `modes`, идентификатор режима по умолчанию `defaultModeId` и массив `tokens`. Для каждого токена сохраняются исходное имя и массив сегментов `path`, тип Pixso, описание, области применения, имена для кода и значения `valuesByMode`. Цвета сохраняются в исходных компонентах RGB(A), ссылки — в виде `{"type":"VARIABLE_ALIAS","id":"…"}`.

У подключённых библиотек Pixso отдаёт названия и ключи коллекций, а также названия, ключи и типы переменных. Чтобы выгрузить режимы, значения и ссылки, откройте сам файл библиотеки и запустите плагин в нём. Для коллекций подключённых библиотек поля режимов и значений остаются пустыми. Плагин читает данные Variables без импорта переменных в документ.

[Документация Pixso по локальным переменным](https://pixso.net/developer/en/plugin-api/variables/variables.html)
