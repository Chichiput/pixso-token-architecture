# Архитектура токенов для Pixso

Плагин показывает и выгружает локальные переменные открытого файла Pixso. Коллекции и группы видны в дереве, которое строится по разделителям `/` в именах переменных. В предпросмотре можно выбрать коллекцию и режим, найти токен, посмотреть образец цвета или проследить цепочку ссылок.

## Установка

1. Распакуйте архив и откройте нужный дизайн-файл в настольном Pixso.
2. Откройте панель плагинов и выберите «Создать плагин» / Create Plugin. В некоторых версиях этот пункт доступен через контекстное меню «Плагины → Разработка плагинов».
3. Выберите `manifest.json` из распакованной папки. Оставьте `main.js` и `ui.html` рядом с манифестом.
4. Запустите «Архитектура токенов» из списка локальных плагинов.

Сборка и установка зависимостей не требуются.

## Предпросмотр и экспорт

- «Дерево токенов» показывает значение для выбранного режима. При ссылке на другую локальную коллекцию предпросмотр использует её выбранный режим или режим по умолчанию. Для ссылок на внешние либо недоступные переменные дерево показывает их идентификаторы.
- «Обновить» заново читает данные открытого файла.
- «Скачать JSON» выгружает `pixso-tokens.json`. В JSON входят все локальные коллекции, режимы и токены независимо от фильтров. Вкладка «JSON» показывает содержимое экспортируемого файла и позволяет скопировать его вручную, если среда Pixso ограничивает скачивание.

## Формат файла

Корневой объект содержит `schemaVersion` и массив `collections`. У коллекции есть идентификатор, имя, список режимов `modes`, идентификатор режима по умолчанию `defaultModeId` и массив `tokens`. Для каждого токена сохраняются исходное имя и массив сегментов `path`, тип Pixso, описание, области применения, имена для кода и значения `valuesByMode`. Цвета сохраняются в исходных компонентах RGB(A), ссылки — в виде `{"type":"VARIABLE_ALIAS","id":"…"}`.

Источник токенов — локальные переменные Pixso. Отдельные стили и переменные подключённых библиотек в выгрузку не входят. Данные обрабатываются внутри плагина.

[Документация Pixso по локальным переменным](https://pixso.net/developer/en/plugin-api/variables/variables.html)
